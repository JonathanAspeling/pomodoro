## ⚠️ Key Principles
*   **Atomic Tasks:** Each task must be a single, verifiable unit of work.
*   **CLI First:** All metadata changes *must* use the Backlog.md CLI to maintain synchronization.
*   **Definition of Done:** A task is only complete when all Acceptance Criteria and Definition of Done items are checked off, and the Final Summary is written.
